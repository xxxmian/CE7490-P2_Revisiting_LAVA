# LAVA 项目重建与复现差异报告

## 结论与适用边界

本项目是从两份交付物做的机制重建，而不是恢复原代码或原始随机实验。原附件中的 `377cbb1`、`experiment-final-v2` 只是文本标识；没有 Git 对象、原 trace、源码或逐种子结果可供恢复。相同种子编号也不足以生成原 trace，因为原随机数库、抽样顺序及分布参数未知。

新结果应写作“独立重建，在声明的合成参数下运行”，不能写作“原结果已精确复现”。原报告中的正结果、85% 显著性阈值及默认模型的 Host-Level 优势在本项目中都只属于待检验的历史主张。**没有根据新测试结果调整 workload、阈值或规则以追平这些数字。**

本次实际执行 1,644 次报告规模仿真，16 项独立单元测试全部通过，所有运行均无调度失败和资源超分配。但默认预测器下，Host CA 相对 Best-Fit 的新结果为 −0.0446 pp，95% CI [−0.1381, +0.0489]，**未复现报告中的显著优势**。准确率扫描的首个显著正收益点为 75%，新验证集选择阈值为 0.5，也分别不同于报告的 85% 和 0.3。完整数值在实测附录中列出。

## B. 用公开论文补足的机制（不是从丢失项目恢复）

核对来源：Ling et al., *LAVA: Lifetime-Aware VM Allocation with Learned Distributions and Adaptation to Mispredictions*, https://arxiv.org/html/2412.09840v1 ，§4.2–4.3。此页面是 2024 arXiv v1；课程报告引用 MLSys 2025，不应视为逐行同一版本。

- LAVA 类边界使用 1、10、100 小时，最后一类无穷上界；deadline 的最后一级取 1,000 小时。
- NILAS temporal cost 边界使用 0,.5,1,1.5,2,3,4,6,12,24,168 小时。
- LAVA 优先 recycling 且高于 VM 类别的主机（类别差越小越优），然后相同类别 open 主机，然后其他非空主机，最后空主机；用 temporal cost 及资源分数打破平局。
- recycling 的残余 VM 全退出后主机降一类，仍在主机的 VM 成为新残余集；deadline 到期升一类并刷新残余集。

这些补足使机制具体可执行，仍不能证明与课程原实现相同。原论文用 LAS 名称，课程项目叫 NILAS；本重建保留课程命名，并实现其非侵入式 temporal-cost 思路。

## C. 必须声明为合理推断的实现

| 缺失项 | 重建中的具体选择 | 可能影响 |
|---|---|---|
| 到达过程 | 独立指数 interarrival，rate=8/hour，第一条 VM 在首次抽样时到达 | 突发度、并发量 |
| profile 比例 | interactive/batch/service = .45/.35/.20 | 长 VM 资源占比、置信度序列 |
| 双指数参数 | `(p_short,mean_short,mean_long)` = interactive (.9,.3,8)，batch (.65,2,30)，service (.3,4,120)，小时 | 是关键未知参数，强烈影响全部结论 |
| VM 形状及比例 | (.125,.125)、(.25,.125)、(.125,.25)、(.5,.25)、(.25,.5)，权重 .35,.2,.2,.125,.125 | 资源碎片、可回收程度 |
| profile/shape 关联 | 独立；寿命不截断，仅预测 cap=336h | 尾部、主机占用 |
| Best-Fit | 剩余 CPU 和内存的平方和最小；主机 id 确定性破平局 | 放置路径及随机差异 |
| LA fallback | 同初始二类非空主机→其他非空→空，再 Best-Fit | 与未知原始实现可不同 |
| 受控噪声重复预测 | 首次对总寿命注入一次噪声，固定预测总时长；未到预测退出时减 uptime，过期后用 `max(.1,uptime)`（cap 336h）作为剩余估计 | **重要近似**；没有恢复课程中的重预测算法 |
| 受控置信度 | log10 总寿命上的 log-uniform prior 加全局正确率/两种 sigma 的混合后验，条件化存活；计算预测剩余类内质量 | 与报告原置信度不唯一对应，不能保证 50% 以上全部通过 |
| cap 的统计处理 | 观测预测被 cap，但置信度把 cap 后数值当普通观测，不建模 censoring 的点质量 | 在 14 天边界附近存在校准误差 |
| synthetic 预测 cap | 条件均值 cap 到 336h；概率质量仍来自完整条件混合分布 | 极长 uptime 下类别概率 |
| 类边界 | 左闭右开，预测恰等于 1/10/100h 时进入较高类 | 边界行为 |
| deadline | 初始 `now+class_upper`；降级从当前时刻重设，升级从旧 deadline 滚动，最高类继续刷新；仅在到达前懒更新 | 时间尺度及 cohort 行为 |
| 回退的生命周期 | 所有放置均维护主机生命周期；混放不改变首个 VM 赋予的 mode | VM CA 污染诊断定义 |
| 阈值验证目标 | synthetic 验证集上，相对 LAVA 和 VM CA 平均收益最大；并列取最小阈值 | 报告叙述与 Fig.5 纵轴不能唯一确定聚合目标 |
| packing density | 非空主机 CPU/内存占用率均值，按有非空主机的时间积分 | 仅为明确的 secondary 指标 |

这些不是从数据拟合出来的参数；是一次声明后固定的合成默认值。没有做 workload 搜索。
